# Sokar Ai Services - الدليل الاسترشادي الموحد للخدمات الحكومية 🇪🇬

منصة **Sokar Ai Services** هي دليل استرشادي توجيهي متكامل يهدف إلى التيسير على المواطنين والطلاب في جمهورية مصر العربية من خلال تجميع وإتاحة تفاصيل الخطوات والأوراق والمستندات والرسوم التقديرية للمعاملات الحكومية المختلفة، وتوفير روابط مباشرة للبوابات الرسمية المعتمدة.

---

> ⚠️ **إخلاء مسؤولية تنبيهي هام:**  
> هذا الموقع هو **موقع استرشادي وتوجيهي خاص بـ Sokar Ai Services**، وهو **غير تابع للحكومة المصرية أو أي جهة أو وزارة أو هيئة حكومية رسمية**.  
> هدف المنصة هو تقديم الإرشادات وتجميع الروابط المباشرة للبوابات والمنصات الرسمية لتسهيل الوصول، دون جمع أو معالجة أي بيانات شخصية أو رقم قومي.

---

## 🌟 الميزات الرئيسية

- **دليل الخدمات المعاملاتية:** تغطية شاملة لخدمات الأحوال المدنية (بطاقات الرقم القومي)، المرور ورخص القيادة، الشهر العقاري والتوثيق، الإسكان الاجتماعي، الكهرباء والعدادات الكودية، والخدمات التعليمية.
- **حاسبة الرسوم والتكاليف:** تقدير التكلفة الإجمالية والمدة المتوقعة لاستخراج المستند المعين.
- **فاحص الجاهزية والمستندات:** قائمة فحص تفاعلية مجهزة تتيح للمواطن طباعة أو حفظ قائمة الأوراق المطلوبة قبل التوجه للجهة الرسمية.
- **دليل الخطوط الساخنة ومراكز الخدمة:** خريطة تفاعلية وأرقام الطوارئ والخط الساخن للوزارات والهيئات الحكومية.
- **إتاحة الوصول وسهولة الاستخدام:** أدوات تغيير حجم الخط، وضع التباين العالي، وخاصية الاستماع الصوتي للتعليمات.
- **الشروط والأحكام وسياسة الخصوصية:** نافذة تفاعلية (`TermsAndPrivacyModal`) تعرض بنود الاستخدام والتزام المنصة بعدم تخزين أي بيانات شخصية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Front-End:** [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation & Visuals:** [Motion](https://motion.dev/), [Lucide React Icons](https://lucide.dev/)
- **Back-End Server:** [Express.js](https://expressjs.com/), Node.js
- **Build System:** [Vite](https://vitejs.dev/), [esbuild](https://esbuild.github.io/), `tsx`

## 🚀 تشغيل المشروع محلياً (Development Setup)

### 1. تثبيت الاعتمادات (Install Dependencies)
```bash
npm install
```

### 2. تشغيل بيئة التطوير (Run Development Server)
```bash
npm run dev
```

### 3. بناء وتجميع المشروع للإنتاج (Production Build)
```bash
npm run build
```

### 4. تشغيل خادم الإنتاج (Start Production Server)
```bash
npm run start
```
